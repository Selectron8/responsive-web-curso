Este repositorio contiene las prácticas, proyectos y ejercicios realizados durante el **Curso de Desarrollo Web Responsive**. El objetivo principal es construir una página web adaptativa que ofrezca una experiencia visual y funcional óptima en cualquier tipo de dispositivo (escritorio, tablet y móvil).

---

## 🚀 Características y Conceptos Desarrollados

- 📱 **Enfoque Mobile-First**: Estrategia de diseño comenzando desde pantallas pequeñas hasta adaptar el diseño a pantallas grandes.
- 📐 **Media Queries**: Uso de puntos de ruptura (*breakpoints*) para adaptar el maquetado según la resolución de la pantalla.
- 📦 **Layouts Flexibles**:
  - **CSS Flexbox**: Distribución dinámica y alineación de elementos en componentes y listas.
  - **CSS Grid**: Estructura general de maquetación y cuadrículas responsivas.
- 📏 **Unidades Relativas**: Aplicación de `rem`, `em`, `%`, `vw` y `vh` para tipografías e imágenes fluidas.
- 🖼️ **Imágenes Responsivas**: Optimización y adaptación del contenido multimedia según el dispositivo.
- 🏗️ **HTML5 Semántico**: Uso correcto de etiquetas estructurales (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
