responsive-web-curso

Este es un ejercicio básico de desarrollo web centrado en la creación de una tienda con diseño responsive utilizando tecnologías fundamentales del lado del cliente.
📝 Descripción
El proyecto consiste en la maquetación de una tienda virtual adaptada a diferentes dispositivos (móvil, tablet y escritorio). Se ha puesto especial énfasis en la estructura semántica y el diseño fluido mediante CSS.
🛠️ Tecnologías utilizadas
Según las estadísticas del repositorio, el proyecto se compone de:

    HTML (54.4%): Estructura del sitio web.
    CSS (38.0%): Estilos y diseño responsivo.
    JavaScript (7.6%): Funcionalidad básica del lado del cliente.

📂 Estructura del Proyecto
El repositorio está organizado de la siguiente manera:

    index.html: Archivo principal de la tienda.
    /css: Contiene las hojas de estilo del proyecto.
    /img: Carpeta destinada a los recursos visuales e imágenes de productos.
    /js: Archivos de lógica JavaScript.
    /partials: Fragmentos de código reutilizables para la estructura.

🚀 Instalación y Uso
Para visualizar este proyecto localmente:

    Clona el repositorio:
    Abre el archivo principal: Navega a la carpeta del proyecto y abre index.html en tu navegador preferido.
